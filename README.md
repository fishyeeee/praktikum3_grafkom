# Praktikum 03 - WebGL2 Transformasi

Aplikasi WebGL2 interaktif untuk menerapkan:

- Translation
- Rotation
- Uniform Scaling
- Non-uniform Scaling
- Model Matrix 3x3
- Transform Composition
- State-based Keyboard Input
- deltaTime
- Automatic Animation
- Transform Order
- HUD
- Coordinate Axis
